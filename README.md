# Customer Segmentation Analysis

## 📊 Project Overview
This project analyzes customer purchase data from the U.S. market to identify patterns, customer segments, and business strategies.

## 📁 Files
- Customer Segmentation Analysis.pptx
- project_shopping_trends.xlsx
- customer_clusters.xlsx

## 🔍 Analysis Performed
- Product Category & Discounts
- Customer Spending by Age Group
- Seasonal & Location Analysis
- Customer Segmentation

## 📈 Key Insights
- Clothing is the top-performing category
- Middle-aged customers use cards the most
- Seasonal demand varies by region
- 3 customer segments identified

## 🛠 Tools Used
- Microsoft Excel
- Data Analysis Techniques
- Statistical Insights
